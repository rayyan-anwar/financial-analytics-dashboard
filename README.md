# Financial Analytics Dashboard

Production-minded financial analytics dashboard for market exploration, volatility, drawdown, portfolio-oriented metrics, visualization and risk intelligence.

**Author:** Rayyan Anwar  
**Positioning:** AI/ML · Data Analytics · Technology Management

## Architecture
Market Data → Validation → Returns & Indicators → Risk Metrics → Dashboard / API

## Features
- Historical return analysis
- Annualized volatility
- Maximum drawdown
- Sharpe-style ratio
- CSV upload
- Interactive chart
- FastAPI health endpoint
- Streamlit UI
- Tests, Docker and CI

## Responsible Use
Educational and analytical system only. Metrics are historical and assumption-dependent; they are not personalized investment advice.
